# 🎓 CampusMate — Student Management Web App

CampusMate is a student management web application designed to help students organize their academic life in one place.

## ✨ Features

- 🏠 **Dashboard** — View student information and upcoming classes.
- 📊 **Attendance Management** — Track attendance for different subjects.
- 🗓️ **Timetable** — View your weekly class schedule.
- 📅 **Calendar** — Add, manage, and track important events.
- 📝 **Notes** — Create and organize study notes.
- 📚 **Assignments** — Manage academic tasks and track completion.
- 👤 **Profile Settings** — Manage student information.
- 🪪 **Digital ID Card** — View your digital student ID.

## 🛠️ Technologies Used

- React.js
- JavaScript
- JSX
- CSS
- Browser localStorage

## 💡 Objective

To provide students with a simple and convenient platform for managing attendance, classes, notes, assignments, and important academic events.

## 💾 Data Storage

The application uses browser localStorage to preserve supported data between page refreshes. Data is stored locally in the browser rather than in a shared online database.

## 🚀 Future Improvements

- Student login and authentication
- Notifications for assignments and events
- Mobile-friendly enhancements
